Docspeed provides AP invoice extraction focused on Indian GST invoices for BPO and shared‑services teams. The service extracts GSTIN, vendor details, tax blocks, totals and line items and presents grounded, source‑linked evidence to speed exception handling. It is built for procurement and finance workflows that require structured, trusted data before production rollout.

**Areas:** AP Invoice Extraction · BPO · Shared Services · Document AI · Financial Services · Procurement Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Docspeed: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
